Numerical Methods — Roots & Systems of Equations

Closed — System Solver
Jacobi Iteration Method
Solves a diagonally-dominant linear system Ax = b. Each variable is updated using values from the previous iteration only.
Enter matrix size (n×n). Fill in coefficients aij and constants bi. Uses tolerance ε = 10⁻⁶ automatically.
Closed — System Solver
Gauss-Seidel Method
Like Jacobi but each variable is updated immediately using the latest values — typically converges faster.
Same input format as Jacobi. Tolerance ε = 10⁻⁶.
Closed — Root Finding
Bisection Method
Repeatedly halves an interval [a, b] where f(a)·f(b) < 0 until the root is isolated to the required precision.
⚠ Trig functions computed in radians. Supported: sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, asinh, acosh, atanh, exp, log, log10, sqrt, abs, pi, e
f(x) — write as a math expression. Example: x - cos(x) or 3*x^2 - exp(x)
Closed — Root Finding
False Position (Regula Falsi)
Uses the x-intercept of the secant line through (a, f(a)) and (b, f(b)) as the next approximation.
⚠ Trig functions computed in radians. Same function syntax as Bisection.
Open — Root Finding
Newton-Raphson Method
Uses the tangent line at each estimate: xk+1 = xk − f(xk) / f′(xk). Requires an initial guess and the derivative.
⚠ Trig functions computed in radians. f′(x) is computed via automatic numerical differentiation if left blank.
Open — Root Finding
Secant Method
Approximates the derivative using a finite difference: f′(xk) ≈ [f(xk) − f(xk-1)] / (xk − xk-1). No derivative required.
⚠ Trig functions computed in radians.
Regression
Linear Least Squares
Fits y = ax + b to a set of data points by minimising the sum of squared residuals.
Enter x values and y values, comma-separated (same number of points).
⚠ Trig functions computed in radians. For non-linear models, linearisation is applied where possible.
Enter x, y pairs and specify the non-linear model. Supported linearisable models: y=a*exp(b*x), y=a*x^b, y=a+b*ln(x)
